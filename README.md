# sim_spaceballoon
physics simulation to test rockets beginning to operate at high altitudes, launched from hydrogen balloon
CREATED ENTIRELY USING GPT-5.6 Sol




CONTROLS:
scroll - zoom in and out
reset - double click mouse wheel
pan - left click




IMPORTANT ADJUSTABLE PARAMETERS:

BALLOON_PAYLOAD_MASS - mass carried by balloon
BALLOON_ENVELOPE_MASS - actual balloon mass

BALLOON_LAUNCH_DIAMETER - balloon diameter at ground level

BALLOON_BURST_DIAMETER - diameter balloon will burst at

BALLOON_CD - drag coefficient (0.47 sphere like)

BALLOON_VIRTUAL_MASS_COEFF - virtual mass coefficient (0.5 default)

BALLOON_START_ALTITUDE - start altitude


SIMULATION_SPEED - simulation time passing speed (1.0 is normal time passing)


R_HYDROGEN -hydrogen specific gas constant (4124.0 J / (kg K))

R_AIR -air gas constant (287.05  J / (kg K))

G0 -acc due to gravity @0km (9.80665 m/s^2)
